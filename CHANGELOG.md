# Changelog

Notable changes to Family Health. Versions follow [Semantic Versioning](https://semver.org/).

## Unreleased

- The Android download is about 22 MB instead of 48 MB. It is for 64-bit phones only, and the universal, 32-bit and x86 files are no longer published.
- Android, macOS and iOS each get their own release and tag, like `android-v1.0.0`, so one platform failing doesn't hold back the others.
- Every change to the app now publishes a release by itself, with the next patch version.

## 1.0.0 - 2026-10-30

First public release: family profiles, doctors, lab reports with on-device reading, trend charts, needs-attention dashboard, documents, optional AI reading, follow-ups, medicine reminders, encrypted storage and backups, for macOS, iPhone, iPad and Android.
