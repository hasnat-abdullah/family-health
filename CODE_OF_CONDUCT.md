# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good intent, and keep discussion about the work.

Report unacceptable behaviour to the maintainer through [a private security advisory](https://github.com/hasnat-abdullah/family_health/security/advisories/new) or by contacting them on GitHub. Reports are handled in confidence.
